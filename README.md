# Quorista Overseas — V4 Destination First

A static one-page website for **Quorista Overseas**, designed around the supplied destination and university visual references.

## Included
- 14 real destination images cropped from the supplied destination collage.
- Destination atlas with region filters and click-to-open destination details.
- Study Abroad and Tourism pathway sections using supplied university/travel imagery.
- University reference wall with an explicit **not official partners** disclaimer.
- Scholarship spotlight.
- Service journey and process sections.
- Lead enquiry form using FormSubmit AJAX.
- WhatsApp, email and Instagram contact links.
- Responsive mobile navigation and layout.
- Privacy and Terms pages.
